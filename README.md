# DMC DevOps

![CI Status](https://github.com/armandochavez/dmc-devops/actions/workflows/ci.yml/badge.svg)

## Descripción

Repositorio de documentación para prácticas del curso de DevOps.
Este proyecto demuestra un flujo de trabajo DevOps integrado con Jira y GitHub.

## Contexto

Los cambios en este repositorio se realizan mediante Pull Requests
siguiendo GitHub Flow y están vinculados a issues de Jira.
